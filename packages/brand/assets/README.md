# Brand assets

Place brand files here (replace the placeholders if present):

- `flc-logo.svg`
- `icon-1024.png`
- `icon-512.png`
- `icon-192.png`

Import via `@app/brand/assets/<filename>` or path helpers from `@app/brand`.

For the web favicon, also copy `icon-192.png` to `apps/web/public/icon-192.png`.
